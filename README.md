# 💌 An Interactive Apology Website

A cute, playful, and interactive multi-page apology website with pastel styling, animated illustrations, playful interactions, and a celebration finish!

## ✨ Features
- **Page 1 (The Letter)**: Two-column greeting card with a rotating starburst badge and a realistic tilted pastel sticky note.
- **Pages 2–12 (Pleading Sequence)**: 14 bespoke vector stickers and pleading prompts.
- **Forgiveness Shortcut**: Clicking any positive button on any card jumps straight to forgiveness!
- **Page 13 (The Trick Page)**: A runaway "No" button that teleports whenever the cursor approaches, ensuring only "Fine! forgiven" can be clicked.
- **Page 14 (Success Celebration)**: Full-screen canvas confetti shower (hearts & stars) with synthesized Web Audio chimes and a replay option.
- **Personalization**: Customize recipient and sender names live or via URL query parameters (`?to=Name&from=Name`).
- **Sound Effects**: Zero-dependency Web Audio sound effects with mute toggle.

## 🚀 Running Locally
Open `index.html` directly in any web browser, or run the included PowerShell server:
```powershell
powershell -ExecutionPolicy Bypass -File server.ps1
```
Then visit [http://localhost:8080/](http://localhost:8080/)!
